# 📄 Project-K18516913 (B2B/B2C E-commerce платформа)

Project-K18516913 — это масштабируемая распределенная микросервисная e-commerce система для продажи крепежа и строительных материалов.
Проект разработан с упором на отказоустойчивость, высокую производительность и поддержку сложной бизнес-логики оптовых продаж, используя передовые подходы экосистемы .NET и событийно-ориентированную архитектуру.

## ✨ Ключевые возможности

* 🛍 Мультиканальность: Кроссплатформенное мобильное приложение и веб-витрина для взаимодействия с пользователями.
* 🧮 Продвинутое ценообразование: Динамический пересчет стоимости в реальном времени с учетом многоуровневых оптовых порогов и жестких ограничений по кратности фасовки.
* 📦 Изолированные микросервисы: Независимые и слабосвязанные сервисы для Каталога, Корзины, Заказов, Оплаты, Инвентаря и Идентификации пользователей.
* 🔄 Событийно-ориентированная архитектура (EDA): Асинхронное взаимодействие микросервисов (напр., надежное бронирование остатков склада) через обмен доменными событиями с помощью брокера сообщений.
* 💳 Платежный шлюз: Безопасное оформление заказов, система обработки платежных вебхуков и встроенный Mock-эмулятор для локального тестирования транзакций.

## 🛠 Технологический стек

* Платформа: C# / .NET 10
* Пользовательский интерфейс: .NET MAUI (MVVM через `CommunityToolkit.Mvvm`) и React (Vite).
* Архитектура: Microservices, Domain-Driven Design (DDD), Clean Architecture, CQRS.
* Базы данных и Кэш: PostgreSQL (с EF Core), MongoDB, Redis (StackExchange.Redis).
* Брокер сообщений: RabbitMQ с использованием абстракции MassTransit.
* Инфраструктура и Оркестрация: .NET Aspire, YARP (API Gateway), MinIO (S3-хранилище), Docker.
* Мониторинг и Тестирование: OpenTelemetry, xUnit, Testcontainers, NetArchTest.

## 🏗 Архитектура проекта (Clean Architecture & Microservices)

Решение разбито на независимые микросервисы, каждый из которых построен по принципам Чистой Архитектуры:

1. `Krepim.AppHost` & `Krepim.ServiceDefaults` — Оркестрация локальной среды разработки через .NET Aspire (автоматический запуск БД, брокеров, сервисов) и общая конфигурация OpenTelemetry.
2. `Krepim.ApiGateway` — Единая точка входа на базе YARP. Отвечает за маршрутизацию запросов от клиентов к микросервисам и централизованную проверку JWT-токенов.
3. `Krepim.[Service].Domain` — Сердце каждого микросервиса. Богатая предметная модель (Rich Domain Model), агрегаты (AggregateRoots), Value Objects и доменные правила (например, логика корзины или товара).
4. `Krepim.[Service].Application` — CQRS-ядро на базе `MediatR`. Содержит обработчики команд и запросов, а также строгую валидацию пайплайнов через `FluentValidation`.
5. `Krepim.[Service].Infrastructure` — Работа с PostgreSQL (миграции EF Core), MongoDB, кэшированием в Redis, а также `Consumers` для прослушивания очередей MassTransit.
6. `Krepim.Mobile` & `Krepim.Web.Client` — Фронтенд-часть. Клиентские приложения, взаимодействующие с бэкендом исключительно через API Gateway.
